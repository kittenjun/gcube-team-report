3. 추가 검토 및 담당 배정이 필요한 과제

3.1 PC방 프로젝트

  • 1페이즈 기능 구현과 안정화, 2페이즈를 위한 데이터 수집은 완료했습니다.

  • 2페이즈 계획과 범위를 구체화하기에 앞서, 관련 기능과 운영 구조에 대한 교육을 우선 진행할 필요가 있습니다.

  • 교육 이후 추진 범위와 담당을 결정합니다.

3.2 Kubernetes 전환 시 API Gateway 운영 구조

  • Kubernetes로 운영 환경을 전환할 경우, Istio 활용을 검토합니다.

  • 현재 API Gateway의 역할과 Istio 적용 범위를 정리합니다.

  • 사이드카 등을 통한 별도 구현이 필요한 기능을 공유한 뒤 담당자를 배정합니다.

3.3 관리자 콘솔

  • 영업·마케팅·운영·개발 등 부서별 업무 특성에 맞춰 필요한 기능을 구분하고 개선할 필요가 있습니다.

  • 시급한 과제는 아니므로 우선 보류합니다.

  • AI Agentic 팀 워크플로우와 시스템이 마련된 이후 업무 배정을 검토합니다.

3.4 AI Agentic 개발 체계 구축

  • 전담 인력이 충원되면 추진합니다.

  • 충원이 이루어지지 않을 경우에는 보류합니다.

4. 진행 및 공유 사항

각 담당자는 위 방향을 기준으로 세부 작업 범위와 진행 계획을 구체화합니다. 진행 과정에서 확인한 구조, 기술 및 개선 사항은 팀 내에 공유하여 함께 활용할 수 있도록 합니다.
